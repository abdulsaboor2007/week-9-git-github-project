# Simple Calculator

## Project Description
This is a beginner-level calculator created with Python.
It performs basic arithmetic operations on two numbers.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Division-by-zero checking

## Python Concepts Used
- input()
- print()
- Variables
- float()
- if, elif and else
- Arithmetic operators

## How to Run
1. Open the project folder in VS Code.
2. Open the terminal.
3. Run:
python calculator.py
